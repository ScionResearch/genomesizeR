# Plot genome size tree

This function loads a result table from estimate_genome_size and plots a
taxonomic tree with colour-coded estimated genome sizes.

## Usage

``` r
plot_genome_size_tree(output_table, refdata_path)
```

## Arguments

- output_table:

  Result table from estimate_genome_size

- refdata_path:

  Path to the downloadable archive containing the reference databases
  and the bayesian models
